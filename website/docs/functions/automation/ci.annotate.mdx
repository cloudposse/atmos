<Intro>
    The `ci.annotate` function attaches an error, warning, or notice to a file and line, so it appears inline on the
    pull request diff. Locally, it prints the same information as a compiler-style line on stderr.
</Intro>

## Usage

```python
ci.annotate(level, message, file = "", line = 0, end_line = 0, title = "")
```

## Arguments

<dl>
    <dt>`level`</dt>
    <dd>Required. The severity, as a string: `"error"`, `"warning"`, or `"notice"`. Any other value fails with an argument error.</dd>

    <dt>`message`</dt>
    <dd>Required. The text of the annotation, as a string.</dd>

    <dt>`file`</dt>
    <dd>
        (Optional) The path of the file the annotation belongs to, relative to the repository root. Pass it together
        with `line` to place the annotation on a diff line.
    </dd>

    <dt>`line`</dt>
    <dd>(Optional) The first line the annotation covers, as an integer. The default of `0` means no line.</dd>

    <dt>`end_line`</dt>
    <dd>(Optional) The last line the annotation covers, as an integer. Use it to highlight a range.</dd>

    <dt>`title`</dt>
    <dd>(Optional) A short heading shown above the message.</dd>
</dl>

## Returns

The return value is `None`.

## Behavior

- In CI, the annotation appears on the changed line in the pull request diff and in the run's annotation list.
- Locally, the call prints `file:line: level: message` on stderr.
- In CI the call is gated by `ci.annotations.enabled`. When it is off, the call warns, renders locally, and the
  script continues. See [gating](/functions/automation/ci#gating) and the [CI configuration](/cli/configuration/ci).

## Examples

### Flag a line in a file

```python
ci.annotate("warning", "This image tag is not pinned", file = "stacks/prod.yaml", line = 14, title = "Unpinned image")
```

Locally this prints `stacks/prod.yaml:14: warning: This image tag is not pinned`.

### Report each finding from a check

```python
findings = json.decode(exec.run(["tflint", "--format=json"], check = False, output = "capture").stdout)
for issue in findings["issues"]:
    ci.annotate(
        "error",
        issue["message"],
        file = issue["range"]["filename"],
        line = issue["range"]["start"]["line"],
        end_line = issue["range"]["end"]["line"],
        title = issue["rule"]["name"],
    )
```

## Errors

- An unknown `level`, or a missing `message`, fails with an argument error that names `ci.annotate`.
- A gated-off call never fails.
