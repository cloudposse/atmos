<Intro>
    The `os.platform` attribute is a read-only string identifying the operating system of the running Atmos executable.
</Intro>

## Usage

```python
os.platform
```

Common values are `"linux"`, `"darwin"` (macOS), and `"windows"`. Values follow Go's operating-system names.
Read the attribute directly, without parentheses. Environment variables cannot override it.

## Examples

```python
suffix = ".exe" if os.platform == "windows" else ""
exec.run(["my-tool" + suffix, "--version"])
```
