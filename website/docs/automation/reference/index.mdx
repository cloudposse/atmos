## What this reference covers

The language is Starlark with four options that Atmos turns on: control flow such as `if` and `for`
at the top level of a file, `while` loops, sets through the `set()` function, and recursion.
Atmos uses `.star` files for standalone scripts. Values such as integers,
strings, lists, and dictionaries are built into the language. Atmos also supplies
`sum()` and `round()` for numeric calculations. Functions for
running commands and reading component configuration are supplied by Atmos.

This reference covers the language. For the Atmos-supplied helpers and values, such as
`exec.run`, `steps.parallel`, `fs.read_file`, `ctx`, and `output`, see the
[automation function reference](/functions/automation). For how scripts run in each entry point,
see the [script step](/steps/type/script) and the overview in
[Atmos Automation Language](/scripting/language).

## Example: a function and a condition

```python
def capacity(replicas, workers_per_replica):
    if replicas < 1:
        fail("replicas must be positive")
    return replicas * workers_per_replica

print("Total workers: {}".format(capacity(3, 4)))  # Total workers: 12
```
