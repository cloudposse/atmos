[Install Atmos](/install), then pick the tool you already use.

## CloudFormation

In your own project, register an existing template twice and render one instance locally:

```shell
atmos aws cfn init templates/queue.yaml --name orders-blue --name orders-green
atmos aws cfn render orders-blue -s dev
```

Both components belong to the Atmos stack `dev`. Each has its own AWS stack name. [Preview and deploy the instances](/cli/commands/aws/cloudformation/init).

## Terraform and OpenTofu

From a repository where you already run Terraform or OpenTofu, point Atmos at your initialized root module. For a root in `infra/network`, try the plan, then save it under the Atmos stack `dev`:

```shell
atmos terraform plan ./infra/network
atmos stack add ./infra/network -s dev
atmos terraform plan network -s dev
```

The first command runs your native plan in `infra/network`. If both CLIs are installed and the project does not identify an engine, choose one at the prompt or add `--command=tofu` or `--command=terraform`. The saved component remembers the choice. Registration supports local state and keeps the root’s selected workspace. [Register a second deployment](/cli/commands/stack/usage#adopt-a-terraform-or-opentofu-root).

For a runnable example, use `atmos init examples/native-terraform`, enter `native-terraform`, and run `atmos terraform plan vpc -s dev`. The plan shows one local `null_resource` to add. [Explore the example](/components/terraform/brownfield).

## Helm

Render a local chart with the values for dev:

```shell
atmos init examples/helm
cd helm
atmos helm template demo -s dev
```

Look for the Service named `demo` with port `8080`. Rendering runs locally without a Kubernetes cluster. [Install the release on a local cluster](/examples/helm).

## Packer

Build an Alpine image in a local Docker or compatible Podman runtime:

```shell
atmos init examples/packer-docker
cd packer-docker
atmos packer init alpine -s alpine
atmos packer build alpine -s alpine
```

The first Packer command downloads the builder plugin. The build pulls Alpine and commits the provisioned image locally. [Explore the Packer template](/examples/packer-docker).

## Kubernetes and Kustomize

Render manifests without a cluster:

```shell
atmos init examples/kubernetes
cd kubernetes
atmos kubernetes render demo -s dev
```

The output includes the `atmos-demo` Namespace and a Deployment. For an overlay, copy [the Kustomize example](/examples/kustomize) and run the same render command in its directory.
