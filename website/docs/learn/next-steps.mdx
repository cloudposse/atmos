## Build a stack you can reuse {#what-to-build}

Start with one component, such as a VPC, and use it in two environments. This brings imports, inheritance, and stack organization together in a working project.

1. **Start small.** Configure and deploy a single component in a development stack.
2. **Reuse the configuration.** Add a second stack that imports the same defaults and overrides its environment-specific values.
3. **Connect another component.** Use [remote state](/learn/connecting-components) to pass outputs between them.
