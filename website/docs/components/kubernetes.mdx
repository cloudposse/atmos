<Intro>
Kubernetes components let Atmos render and deploy manifests or Kustomize overlays
for each stack. Use them when you want Kubernetes resources to share Atmos stack
variables, inheritance, authentication, and deployment ordering with the rest of
your infrastructure.
</Intro>

For example, a stack can select a Kustomize overlay and pass environment-specific
values to the component:

```yaml
components:
  kubernetes:
    argocd:
      provider: kustomize
      paths:
        - overlays/dev
      vars:
        namespace: argocd
```

The `argocd` key names this component instance. See the
[Kubernetes stack configuration](/stacks/components/kubernetes) for supported
providers, rendering, hooks, and deployment targets.
