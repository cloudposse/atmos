<Intro>
Helm components let Atmos manage chart releases through stack configuration.
Use them when you want chart values, versions, and target namespaces to vary by
stack while sharing Atmos inheritance, authentication, and dependencies.
</Intro>

A component can use a local chart, a chart repository, or an OCI chart. The
`values` map becomes the chart values for that stack:

```yaml
components:
  helm:
    app:
      chart: ./charts/app
      namespace: app
      values:
        replicaCount: 2
```

The `app` key names this component instance. See the
[Helm stack configuration](/stacks/components/helm) for chart references,
values files, repositories, rendering, and deployment targets.
