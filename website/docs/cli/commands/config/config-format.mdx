<Intro>
Format the active `atmos.yaml` file in place, preserving comments, anchors, Atmos YAML
functions, and Go templates.
</Intro>

<CastPlayer title="atmos config format --help" src="/casts/screengrabs/atmos-config-format--help.cast" static chrome />

## Usage

```shell
atmos config format
```

The `fmt` alias is also accepted.

## Examples

```shell
atmos config format
atmos --config ./config/atmos.yaml config format
```

## Flags

<dl>
  <dt>`--config` (string slice, inherited)</dt>
  <dd>Target a specific `atmos.yaml` file instead of the one discovered in the current directory or git root. Must name exactly one file: `config format` edits a single concrete file on disk, so passing more than one `--config` value is rejected as ambiguous.</dd>
</dl>
