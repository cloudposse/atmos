<Intro>
Preview changes to a deployed CloudFormation stack using a temporary changeset.
Atmos displays the changes and removes the changeset without executing it.
This command authenticates and calls AWS.
</Intro>

## Usage

```shell
atmos aws cloudformation diff <component> --stack <stack> [options]
```

## Examples

```shell
atmos aws cloudformation diff vpc -s plat-ue2-dev
```

Diff all or affected components in dependency order:

```shell
atmos aws cloudformation diff --all -s plat-ue2-dev
atmos aws cloudformation diff --affected --base origin/main
```

Diff components selected by tags or labels:

```shell
atmos aws cloudformation diff --all --tags production,tier-1
atmos aws cloudformation diff --affected --labels cost-center=platform
```

## Behavior

Atmos deletes the preview changeset after displaying it, including an empty
changeset or a failed render.

### New Stacks

Previewing a new stack creates an empty `REVIEW_IN_PROGRESS` stack. Atmos
removes it after the preview if this invocation created it and it remains in
that state. Stacks that already existed are preserved.

### Failed Stack Creation

A stack in `ROLLBACK_COMPLETE` cannot be updated. The command fails with a hint
to [delete the failed stack](/cli/commands/aws/cloudformation/delete) and apply again.
