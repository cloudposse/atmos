<Intro>
Preview changes to a CloudFormation stack. This is an alias for
[`diff`](/cli/commands/aws/cloudformation/diff), including its changeset cleanup
and stack-status checks.
</Intro>

## Usage

```shell
atmos aws cloudformation plan <component> --stack <stack> [options]
```

## Examples

```shell
atmos aws cloudformation plan vpc -s plat-ue2-dev

# Plan components filtered by tags or labels (composes with --all/--affected)
atmos aws cloudformation plan --all --tags production,tier-1
atmos aws cloudformation plan --affected --labels cost-center=platform
```

## Arguments

<dl>
  <dt>`component` <em>(required unless selecting multiple components)</em></dt>
  <dd>CloudFormation component name in the Atmos stack.</dd>
