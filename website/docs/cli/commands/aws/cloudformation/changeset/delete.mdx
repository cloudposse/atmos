<Intro>
  Delete a named changeset (`DeleteChangeSet`) without touching the stack
  itself. Use this to clean up changesets created with
  [`changeset create`](/cli/commands/aws/cloudformation/changeset/create) that
  you decided not to execute.
</Intro>

## Usage

```shell
atmos aws cloudformation changeset delete <component> --stack <stack> --changeset-name <name> [options]
```

## Examples

```shell
atmos aws cloudformation changeset delete vpc -s plat-ue2-dev --changeset-name vpc-2026-08-25
```

A changeset name that does not exist on the stack is an error
(`aws/cloudformation changeset not found`) with a hint to run
[`changeset list`](/cli/commands/aws/cloudformation/changeset/list) for the
valid names, never a `deleted` message with exit code 0.

## Arguments

<dl>
  <dt>`component` <em>(required unless selecting multiple components)</em></dt>
  <dd>CloudFormation component name in the Atmos stack.</dd>
</dl>

## Flags

<dl>
  <dt>`--stack`, `-s` <em>(required for a single component)</em></dt>
  <dd>Atmos stack. With bulk selection flags, limits the selected components to this stack.</dd>

  <dt>`--changeset-name` <em>(required)</em></dt>
  <dd>Name of the changeset to delete.</dd>

  <dt>`--auto-approve` <em>(optional)</em></dt>
  <dd>Skip the interactive confirmation prompt. Without it, `changeset delete` prompts for confirmation on a TTY before deleting the changeset.</dd>
