## Usage

```shell
atmos aws cloudformation changeset list <component> --stack <stack> [options]
```

## Examples

```shell
atmos aws cloudformation changeset list vpc -s plat-ue2-dev
```

## Arguments

<dl>
  <dt>`component` <em>(required unless selecting multiple components)</em></dt>
  <dd>CloudFormation component name in the Atmos stack.</dd>
</dl>

## Flags

<dl>
  <dt>`--stack`, `-s` <em>(required for a single component)</em></dt>
  <dd>Atmos stack. With bulk selection flags, limits the selected components to this stack.</dd>

<SelectionFlags />

<GitFlags />
</dl>

## Output

If the stack has no changesets, `changeset list` prints a single line saying
so instead of an empty table.

This command does not fire [lifecycle hooks](/stacks/components/aws-cloudformation#lifecycle-hooks).
