<Intro>
Print the component’s CloudFormation template without deploying it. Inline
templates are evaluated as stack configuration; template files are used as written.
</Intro>

## Usage

```shell
atmos aws cloudformation render <component> --stack <stack> [options]
```

## Examples

```shell
atmos aws cloudformation render vpc -s plat-ue2-dev
```

Render all or affected components in dependency order:

```shell
atmos aws cloudformation render --all -s plat-ue2-dev
atmos aws cloudformation render --affected --base origin/main
```

Render components selected by tags or labels:

```shell
atmos aws cloudformation render --all --tags production,tier-1
atmos aws cloudformation render --affected --labels cost-center=platform
```

## Source and Authentication

Local templates and cached sources can render offline when their configuration
does not require remote lookups. An uncached source must be downloaded first;
private S3 downloads use the component's resolved AWS identity.

Secret and output lookups can also require authentication and network access.
Use `--dry-run` for static validation without downloads or lookups. Use
[`diff`](/cli/commands/aws/cloudformation/diff) to preview changes against AWS.
