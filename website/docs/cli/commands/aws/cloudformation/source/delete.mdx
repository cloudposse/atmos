<Intro>
Use this command to delete the vendored source directory for an `aws/cloudformation` component. This removes the component directory that was created by `atmos aws cloudformation source pull`.

## Usage

```shell
atmos aws cloudformation source delete <component> --stack <stack> [--force]
```

## Description

The `delete` command removes the vendored component directory. Without `--force`, it prompts for confirmation and deletes only after you confirm. Use `--force` to skip the confirmation prompt.

For CI or other unattended use, provide the component, `--stack`, and `--force`. If the directory exists and terminal input is unavailable, running without `--force` returns an interactive-input error and leaves the directory unchanged.

This is useful for:
- Cleaning up vendored components before re-vendoring
- Removing components that are no longer needed
- Resetting to a clean state for troubleshooting

## Examples

### Delete Vendored Component

Remove a vendored component directory without prompting:

```shell
atmos aws cloudformation source delete vpc --stack dev --force
```

Output:
```
Deleting directory: components/cloudformation/vpc
✓ Successfully deleted: components/cloudformation/vpc
```

### Without Force Flag

In an interactive terminal, omit `--force` to review and confirm the deletion:

```shell
atmos aws cloudformation source delete vpc --stack dev
```

The command asks whether to delete the source directory. Choose **Yes!** to delete it, or **No.** to cancel and keep the directory. Without terminal input, use `--force` as shown in the previous example.

## Arguments

<dl>
  <dt>`component`</dt>
  <dd>**Required.** The name of the Atmos component to delete.</dd>
</dl>

## Flags

<dl>
  <dt>`--stack` / `-s`</dt>
  <dd>**Required.** The Atmos stack name. Can also be set via `ATMOS_STACK` environment variable.</dd>

  <dt>`--force` / `-f`</dt>
  <dd>**Optional.** Skip confirmation and delete the source directory. Use this flag for non-interactive deletion.</dd>
</dl>

## Safety

The `delete` command has several safety features:

1. **Confirmation by default** - Prompts before deletion unless `--force` is set; declining preserves the directory
2. **Only deletes source-managed components** - Only works on components with `source` configured
3. **Non-destructive on missing directories** - Shows a warning if the directory doesn't exist instead of failing
