Use this command to inspect which update restrictions CloudFormation enforces.

## Usage

```shell
atmos aws cloudformation get policy <component> --stack <stack> [options]
```

## Examples

```shell
atmos aws cloudformation get policy vpc -s plat-ue2-dev
```

<dl>

## Output

If the stack has no policy set (CloudFormation's default), `get policy` prints
a message saying so instead of an empty body.

If the stack does not exist, `get policy` fails with a stack-not-found error that points at
`atmos aws cloudformation apply`, instead of AWS's raw validation message.

This command does not fire [lifecycle hooks](/stacks/components/aws-cloudformation#lifecycle-hooks).
