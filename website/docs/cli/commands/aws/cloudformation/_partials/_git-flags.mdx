  <dt>`--ref` <em>(optional)</em></dt>
  <dd>Git ref to compare against for affected detection. Used with `--affected`.</dd>

  <dt>`--sha` <em>(optional)</em></dt>
  <dd>Git SHA to compare against for affected detection. Used with `--affected`.</dd>

  <dt>`--repo-path` <em>(optional)</em></dt>
  <dd>Path to an already cloned target repository to use as the affected baseline. Used with `--affected`.</dd>

  <dt>`--clone-target-ref` <em>(optional)</em></dt>
  <dd>Clone the target ref instead of checking it out in the current repository for affected detection. Used with `--affected`.</dd>

  <dt>`--ssh-key` <em>(optional)</em></dt>
  <dd>Path to the SSH private key used to clone the target ref for affected detection. Used with `--clone-target-ref`.</dd>

  <dt>`--ssh-key-password` <em>(optional)</em></dt>
  <dd>Password for the SSH private key used to clone the target ref for affected detection. Used with `--clone-target-ref`.</dd>
