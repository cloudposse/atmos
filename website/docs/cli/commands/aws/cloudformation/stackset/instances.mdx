## Usage

```shell
atmos aws cloudformation stackset instances <component> --stack <stack> [options]
```

## Examples

```shell
atmos aws cloudformation stackset instances vpc -s plat-ue2-dev
```

List instances for all or affected components in dependency order:

```shell
atmos aws cloudformation stackset instances --all -s plat-ue2-dev
atmos aws cloudformation stackset instances --affected --base origin/main
```

## Arguments

<dl>
  <dt>`component` <em>(required unless selecting multiple components)</em></dt>
  <dd>CloudFormation component name in the Atmos stack.</dd>
</dl>

## Flags

<dl>
  <dt>`--stack`, `-s` <em>(required for a single component)</em></dt>
  <dd>Atmos stack. With `--all`, `--affected`, `--tags`, or `--labels`, this is an optional stack filter; omit it to select components across stacks.</dd>
