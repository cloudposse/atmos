<Intro>
Check whether the component’s template-packaging bucket exists in S3.
The result includes the target name, bucket, region, and existence status.
</Intro>

## Usage

```shell
atmos aws cloudformation backend describe <component> --stack <stack> [options]
```

## Examples

```shell
atmos aws cloudformation backend describe vpc -s plat-ue2-dev
atmos aws cloudformation backend describe vpc -s plat-ue2-dev --format json
```

Disambiguate when the component declares more than one `kind: aws/s3` target:

```shell
atmos aws cloudformation backend describe vpc -s plat-ue2-dev --target artifacts
```

## Arguments

<dl>
  <dt>`component` <em>(required)</em></dt>
  <dd>CloudFormation component name in the Atmos stack.</dd>
</dl>

## Flags

<dl>
  <dt>`--stack`, `-s` <em>(required)</em></dt>
  <dd>Atmos stack.</dd>

  <dt>`--target` <em>(optional)</em></dt>
  <dd>The `kind: aws/s3` provision target to use. Required when more than one is declared.</dd>

  <dt>`--format`, `-f` <em>(optional)</em></dt>
  <dd>Output format: `table` (default), `yaml`, or `json`.</dd>

  <dt>`--identity`, `-i` <em>(optional)</em></dt>
  <dd>Atmos identity to authenticate with.</dd>
</dl>

## Behavior

The command checks the bucket in S3 using the selected target’s identity.

The `table` format prints a header row (`TARGET`, `BUCKET`, `REGION`,
`STATUS`). The `json` and `yaml` formats use snake_case keys, matching the rest
of the CloudFormation output:

```json
[
  {
    "target": {
      "name": "artifacts",
      "bucket": "my-org-cfn-templates",
      "prefix": "vpc",
      "region": "us-east-1"
    },
    "region": "us-east-1",
    "exists": true
  }
]
```
