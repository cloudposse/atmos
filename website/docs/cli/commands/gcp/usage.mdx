<Intro>
Connect Kubernetes tools to GKE using a Google Cloud identity managed by Atmos. Atmos prepares the
cluster configuration and supplies short-lived access tokens as tools need them.
</Intro>

<CastPlayer src="/casts/screengrabs/atmos-gcp--help.cast" static />

## Usage

```shell
atmos gcp <subcommand> [flags]
```

## Examples

```shell
atmos gcp gke token --identity example-deployer
```
