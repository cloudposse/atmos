## Usage

```shell
atmos plugin catalog build <layout> --source=<repository> --output=<file>
```

## Arguments and flags

<dl>
  <dt><code>layout</code></dt>
  <dd>Local release OCI layout.</dd>
  <dt><code>--name</code></dt>
  <dd>Catalog name; defaults to plugins.</dd>
  <dt><code>--source</code></dt>
  <dd>OCI repository where this release will be published.</dd>
  <dt><code>--output, -o</code></dt>
  <dd>Destination catalog YAML file.</dd>
</dl>

## Examples

```shell
atmos plugin catalog build ./oidc-release --source=oci://registry.example.com/team/oidc --output=catalog.yaml
```
