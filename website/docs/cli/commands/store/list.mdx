<Intro>
List the store backends configured under `stores:` in `atmos.yaml`, showing each one's kind, whether it is a secret backend, and which optional capabilities it supports (deletion, a local existence check). `list` shows configured backends, not the keys stored inside them — most backends don't support key enumeration.
</Intro>

<CastPlayer title="atmos store list --help" src="/casts/screengrabs/atmos-store-list--help.cast" static chrome />

## Usage

```shell
atmos store list [flags]
```

## Examples

```shell
# List all configured store backends
atmos store list

# Pipeline-friendly output
atmos store list --format=json
```

## Arguments

<dl>
  <dt>n/a</dt>
  <dd>No positional arguments.</dd>
</dl>

## Flags

<dl>
  <dt>`--format` <em>(alias `-f`)</em></dt>
  <dd>
    The output format: `table`, `json`, `yaml`, `csv`, or `tsv`. Defaults to a styled table on a TTY and plain/delimited output when piped.
  </dd>
</dl>
