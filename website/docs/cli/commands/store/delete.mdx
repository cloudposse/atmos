<Intro>
Remove a value from a configured store backend. Atmos prompts for confirmation before deleting unless you pass `--force`. Returns an error if the backend does not support deletion (for example, Redis or Artifactory). This command is also available under the `rm` and `unset` aliases.
</Intro>

<CastPlayer title="atmos store delete --help" src="/casts/screengrabs/atmos-store-delete--help.cast" static chrome />

## Usage

```shell
atmos store delete STORE KEY [flags]
```

## Examples

```shell
# Delete a value, prompting for confirmation
atmos store delete app-metadata image_tag --stack=prod --component=ecs-service

# Delete without a confirmation prompt
atmos store delete app-metadata image_tag --stack=prod --component=ecs-service --force

# Use the `rm` alias
atmos store rm app-metadata image_tag --stack=prod --component=ecs-service

# Use the `unset` alias
atmos store unset app-metadata image_tag --stack=prod --component=ecs-service
```

## Arguments

<dl>
  <dt>`STORE`</dt>
  <dd>
    The name of the configured store backend to delete from.
  </dd>

  <dt>`KEY`</dt>
  <dd>
    The key to remove.
  </dd>
</dl>

## Flags

<dl>
  <dt>`--stack` <em>(alias `-s`)</em></dt>
  <dd>
    The Atmos stack the key was scoped to when set. **Optional** — must match what was used with `set`.

    **Environment variable:** `ATMOS_STACK`
  </dd>

  <dt>`--component` <em>(alias `-c`)</em></dt>
  <dd>
    The Atmos component the key was scoped to when set. **Optional** — must match what was used with `set`.

    **Environment variable:** `ATMOS_COMPONENT`
  </dd>

  <dt>`--identity` <em>(alias `-i`)</em></dt>
  <dd>
    The identity to use when accessing the store backend.

    **Environment variable:** `ATMOS_IDENTITY`
  </dd>

  <dt>`--force` <em>(alias `-f`)</em></dt>
  <dd>
    Delete the value without prompting for confirmation.
  </dd>
</dl>
