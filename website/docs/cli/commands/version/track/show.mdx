<Intro>
Inspect a version track's effective dependency settings after global defaults, track defaults, and
group policies are applied. Use this view to understand the configuration that controls version
resolution and updates.
</Intro>

## Usage

```shell
atmos version track show [track] [flags]
```

## Examples

```shell
# Show effective entries for prod
atmos version track show prod

# Show effective entries selected by --track as JSON
atmos version track show --track=prod --format=json
```

<TryExample example="version-tracker">

Compare the checked-in dev and prod tracks, then verify their pinned files. This example works offline; no cloud credentials are needed.
