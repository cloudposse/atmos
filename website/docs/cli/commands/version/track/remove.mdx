<Intro>
Stop tracking a dependency by removing its entry from a version track in `atmos.yaml`. Keep your
version configuration focused on the dependencies your project still manages while preserving
comments and formatting.
</Intro>

The alias is `rm`.

## Usage

```shell
atmos version track remove NAME [flags]
atmos version track rm NAME [flags]
```

## Arguments

<dl>
  <dt>`NAME` <em>required</em></dt>
  <dd>Entry name to remove.</dd>
</dl>

## Examples

```shell
# Remove nginx from the default track
atmos version track remove nginx

# Remove nginx from prod
atmos version track rm nginx --track=prod
```
