<Intro>
The `settings.functions` section configures how Atmos evaluates YAML functions in stack manifests.
</Intro>

## Configuration

<File title="atmos.yaml">
```yaml
settings:
  functions:
    exec:
      max_concurrency: 1
```
</File>

## Sections

<dl>
  <dt>[`exec`](/cli/configuration/settings/functions/exec)</dt>
  <dd>Set the maximum number of ordinary `!exec` expressions that can run concurrently during a document evaluation.</dd>
</dl>
