<Intro>
Atmos brings infrastructure, applications, and operational tools into one stack-based configuration system. Manage Terraform and OpenTofu, Kubernetes, Helm, containers, and more with shared configuration, authentication, and automation.
</Intro>

Designed to be cloud agnostic, Atmos enables you to operate consistently across various cloud platforms. Expand a feature to see what it does and open its reference documentation. Features marked experimental in their reference pages follow the [experimental feature settings](/cli/configuration/settings/experimental).

<KeyPoints title="Why Teams Choose Atmos">
- **Reuse Configuration Across Environments** — Share defaults through inheritance, imports, and catalogs
- **Run Infrastructure and Applications Together** — Use components and workflows from local development to production
- **Built-in Compliance Validation** — OPA policies and schema validation catch issues early
- **Keep Local Development and CI Consistent** — Share tool versions, identities, and deployment commands
- **[Proven Design Patterns](/design-patterns)** — Battle-tested approaches for common infrastructure challenges
</KeyPoints>
