# Component Library navigation

The Component Library sidebar, overview table, and Next Steps cards share a list
generated by `component-library.js`. It scans documentation front matter; a page's
folder does not determine whether it is a component overview.

To include a component overview, add:

```yaml
component_library:
  type: example
  label: Example
  position: 10
  implementation: Example source files
  description: What this component helps users do
```

The document's existing ID and URL remain canonical. `position` controls the list
order, with the label breaking ties. Ordinary configuration field pages are excluded.
Custom Components uses `native: false` to appear in navigation and cards without
being counted as a built-in component type.

If another section owns the page, add `reference: true` inside `component_library`
and an absolute `slug` in the document's front matter. The generated sidebar uses a
cross-link, preserving the page's original navigation and breadcrumbs.

To nest a guide beneath a component, add `component_library_parent: example` to
that guide's front matter. Its existing `sidebar_position` and `sidebar_label` (or
`title`) control its order and label. No sidebar edit is needed when adding an
overview or a child guide. Shared overviews cannot own child guides here.

Run `pnpm --dir website test:navigation` to validate the generator and navigation.
