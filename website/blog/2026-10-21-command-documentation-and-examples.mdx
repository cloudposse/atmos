Command help now includes a copyable documentation URL. Use `--docs` to open that
page in your browser, or `--example` to choose a related example and initialize it
locally—even before you have an Atmos project configured.

## Open the documentation

```shell
atmos terraform --help
atmos terraform --docs
atmos terraform plan --docs
```

Help and usage output show the documentation URL, including when redirected to a
file. `--docs` prints the URL and opens it using your browser. These discovery
flags work without a component, stack, Terraform installation, or cloud credentials.

## Try an example

```shell
atmos terraform --example
```

Choose an example from the ordered list; the first is recommended. Atmos shows
its source, destination, and equivalent `atmos init` command, then asks for
confirmation. **No is selected by default.** After you choose Yes, a progress
indicator tracks initialization and Atmos displays the example's README.

Examples install into `./<example-directory-name>`, respecting `--chdir`. Existing
destinations are protected, and initialization does not run Terraform. In a
noninteractive terminal, `--example` prints the available examples and explicit
installation commands without prompting or installing anything.

Commands inherit documentation and examples from their nearest registered
ancestor when they do not have their own. If no example is registered, Atmos
prints an explanation and the documentation URL.
