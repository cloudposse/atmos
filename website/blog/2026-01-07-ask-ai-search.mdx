Finding information in documentation shouldn't require knowing the exact terminology or page structure. With **Ask AI**, you can ask a question in your own words and get an answer assembled from the Atmos docs, with links to the pages it came from.

<!--truncate-->

## The Problem

Keyword search only works when you already know the keyword. If you are trying to find out how Atmos handles a thing, but the docs call that thing something else, the search box has nothing to match on — and a question that spans two or three pages ("what's the difference between imports and inheritance?") has no single page to land on at all. You end up guessing at vocabulary, or reading the sidebar top to bottom.

## The Fix

The search dialog on [atmos.tools](https://atmos.tools) now has a second mode: a chat-style assistant, built on [Algolia DocSearch v4](https://docsearch.algolia.com/docs/v4/askai/).

Nothing about it is trained on Atmos. It retrieves from the same Algolia index that backs the existing keyword search — the crawled content of this documentation site — and uses a language model to turn the passages it retrieves into an answer. That is the useful property: answers come from the current published docs rather than from a model's recollection of Atmos, and every answer cites the pages it drew from, so you can go read the real thing.

The tradeoff is the same one every retrieval system has. If something is not in the docs, Ask AI cannot answer it, and a page that is wrong or stale will produce an answer that is wrong or stale in exactly the same way.

## How to Use It

Visit [atmos.tools](https://atmos.tools) and press `/` or `Cmd+K` to open the search dialog, then switch to the assistant. Keyword search is still there and still the right tool when you know what you are looking for. Questions worth trying:

- "How do I set up AWS SSO with Atmos?"
- "What is the difference between imports and inheritance?"
- "How do I create a custom workflow?"
- "What YAML functions are available?"

Each answer arrives with direct links to the relevant documentation pages.

## Get Involved

If Ask AI gives you a bad answer, that usually means the docs behind it are thin or wrong — which is worth fixing at the source. Tell us at [our issue tracker](https://github.com/cloudposse/atmos/issues).
