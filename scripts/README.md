# Atmos Scripts

This directory contains utility scripts for maintaining the Atmos project.

## NOTICE generation

The `NOTICE` file (license attributions for all Go dependencies) is no
longer generated by a script in this directory. It's now generated by the
Go tool at `tools/noticegen/`, invoked via:

```bash
go tool mage notice:generate
```

Or use the Atmos development shortcut, which runs the slow license scan behind a spinner:

```bash
atmos dev generate notices
```

The same development namespace also exposes mock generation:

```bash
atmos dev generate mocks
```

See `tools/noticegen/README.md` for how it works, its env knobs
(`GO_LICENSES_VERSION`, `LICENSE_GOOS`, `LICENSE_GOARCH`,
`LICENSE_CGO_ENABLED`), and its test suite. License compliance on pull
requests is enforced separately by GitHub's Dependency Review action
(`.github/workflows/dependency-review.yml`), which also checks that
`NOTICE` is up to date by running `go tool mage notice:generate` and
diffing the result.
